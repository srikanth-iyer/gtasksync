gtasksync

gtasksync is a personal tool that lets its owner's AI assistant read and update the owner's own Google Tasks.

It is not a public service and is not offered to other users.

Privacy policy

Built on google-tasks-mcp, an open-source project created by Anton Kutishevsky and its contributors, released under the MIT License. All credit for the original work goes to them. This is a privately modified copy; the changes were made with Claude, Anthropic's AI assistant. If you want to use or host this tool yourself, go to the original project.
