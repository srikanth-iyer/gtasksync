Privacy policy

Last updated: 23 September 2026

gtasksync is a personal tool, run by its owner for their own use only.

What it accesses

With the account owner's permission, gtasksync uses the Google Tasks API to read, create, update and delete tasks and task lists in the owner's own Google accounts. It requests no other Google data.

What it stores

It stores only the sign-in tokens needed to reach Google Tasks, kept encrypted. It does not keep copies of task contents.

Sharing

No data is sold, shared with third parties, or used for advertising. Data from Google APIs is used only to provide this tool's task features, in line with the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be revoked at any time from the Google Account's security settings (Third-party apps with account access).
